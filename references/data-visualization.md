# Data visualization

Read the data contract before drawing. Identify the question, time scope, unit, population, grouping, available comparison, denominator, and exact-value access. Keep the existing calculation source authoritative. Use current real results when the task calls for real data. Avoid inventing coverage, targets, severity thresholds, or category meanings.

- Use position on a shared scale for precise comparison. Choose the simplest representation that answers the question. A table remains useful for exact lookup and editing. Use dots or bars for rank, aligned plots for comparable time series, and a waterfall only for a reconciled start and finish with known contributions.
- Start magnitude bars at zero. Label scales and units. For independently measured quantities, use separate plotting areas and align their time positions when useful. Size the focus for the data actually present. Label any narrower display window and preserve inspectable underlying periods. A gap between observations remains a gap.
- For a change summary, show the prior amount and the known contributions alongside the current amount when they reconcile. Use a concise aligned readout for a few values. Add a chart when the comparison or trend benefits from the geometry.
- Keep observed zero, missing measurement, excluded future period, and zero denominator distinct. Mark the selected period and notable real comparison directly. Use color with text, shape, or line style. Avoid attention-grabbing colors that imply good or bad without a business rule.
- Use direct labels where they fit and a compact legend where they improve clarity. Make exact values and missing reasons available without a pointer. Control label widths with real long categories and realistic numeric precision. Use consistent formatting across charts, tables, and export.
- Apply a small reusable chart style within the installed renderer. Keep axis text, marks, units, rounding, grids, tooltips, and backgrounds coherent across pages. Add a library or advanced mark only when there is a demonstrated task gap.

Reconcile the important numbers, axes, units, and denominators against the source and the exported result. Test gaps, narrow widths, and changed selections against the actual response.
